# 🌍 AirVision - Live Air Quality Monitor

AirVision is a modern web application that provides real-time air quality information, weather updates, and environmental insights for any location. The application combines interactive maps, charts, and health recommendations to help users understand the air quality around them.

---

## Features

- 🌤️ Real-time weather information
- 🌫️ Live Air Quality Index (AQI)
- 📊 Interactive air quality charts
- 🗺️ Interactive location map using Leaflet
- ❤️ Health recommendations based on AQI
- 📱 Fully responsive design
- ⚡ Fast and lightweight interface
- 🔍 Search air quality by city

---

## Technologies Used

- React.js
- HTML5
- CSS3
- JavaScript (ES6)
- Leaflet.js

## Installation

Clone the repository.

```bash
git clone https://github.com/yourusername/AirVision.git
```

Go into the project folder.

```bash
cd AirVision
```

Open **index.html** in your browser.

---

## API

This project uses the OpenWeatherMap API to retrieve:

- Weather data
- Air Quality Index
- Geographic coordinates

Create your own API key from:

https://openweathermap.org/api

Replace the API key inside `app.jsx`.
